FANTAZIA RP 3D v16 — вся браузерная игра, пакет для загрузки через сайт

1. Распакуй этот ZIP в НОВУЮ отдельную папку. Не смешивай с полным архивом.
2. Открой Fantazia-RP-v16-WEB: внутри видны public, server и package.json.
3. На странице загрузки файлов GitHub убери старый незавершённый список.
4. Перетащи СОДЕРЖИМОЕ этой папки, включая public и server, в корень репозитория.
   Не загружай сам ZIP и не внешнюю папку Fantazia-RP-v16-WEB.
   package.json должен лежать в корне рядом с server.js.

Из игры ничего не удалено. Исключены только тесты, документы разработчика,
инструменты Blender и исходные APK/EXE-оболочки. Godot и node_modules отсутствуют.
Полный архив v16 остаётся отдельной копией исходников.

Запуск на ПК: Node.js 22 LTS, затем npm ci и npm start.
Адрес: http://localhost:3000. Один GitHub Pages не запускает Node.js-сервер.
Загрузка файлов в репозиторий сама по себе не подтверждает развёртывание сайта.
Сохранённые места/прогулки находятся в браузере, не в этом ZIP.
