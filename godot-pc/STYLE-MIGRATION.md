# Оформление: браузер → Godot PC 05

Перенесено **оформление основных доступных экранов**, а не все HTML/CSS-окна
браузерной игры. CSS нельзя подключить к Control-узлам как таблицу стилей:
его цвета, композиция и состояния заново выражены через Theme/StyleBox и сцены Godot.

## Источники и соответствия

| Исходник веб-версии | Реализация Godot | Что перенесено |
|---|---|---|
| `public/styles/fz-lobby23.css` | `scenes/main_menu.tscn`, `scripts/ui_theme.gd` | Фон #080e1c, текст #f1f3ff, лавандовый RP 3D, голубая подпись, левое меню, правая карточка, крупная кнопка игры, скруглённые панели |
| `public/styles/fz-neon.css` | Общая Theme, PrimaryButton, фокус/наведение | Голубые/фиолетовые акценты, выделение активной кнопки и вкладки; без мигающих эффектов |
| `public/styles/fz-ui.css`, существующий UI проекта 02 | `hud.gd`, `options_panel.gd` | Родная пауза, прокрутка длинных настроек, читаемые подписи и навигация клавиатурой |
| Кредит `fz-front.js` | Главное меню | Точный текст «Создано при помощи TEMKA_PLAY_OFFICIAL» |
| Информационные карточки лобби | Панели управления, статуса переноса, диагностики | Единые отступы, цвет текста, кнопки возврата и обработка ошибок |

Тема сохранена также в **`ui/native_theme.tres`**, чтобы основные стили были видны
при открытии сцены меню в редакторе, а не только после запуска.
`tests/generate_theme.gd` регенерирует этот ресурс из `scripts/ui_theme.gd`.

## Отличия и ограничения

- Фон главного меню — декоративный 2D-силуэт; для него не загружается игровой GLB.
- Вместо системных веб-шрифтов/Three.js typeface JSON используется шрифт Godot
  с кириллицей. Это не обещание пиксельного совпадения с браузером.
- Сложные CSS-градиенты/тени упрощены до родных StyleBox и 2D-рисования.
  В меню нет второго 3D-рендера, WebView, shader-фона или скрытой сцены города.
- «Аккаунты», «Магазин» и другие пока отсутствующие механики не получили
  фиктивные работающие кнопки. В меню есть честный перечень перенесённого.
- Семисекундная 3D-заставка, весь HUD экономики, чат, магазин, кинотеатр и остальные
  специальные окна v28 **не объявляются перенесёнными** этим обновлением.
- Пауза/настройки игры и экраны загрузки/ошибок используют те же стили.
- Проверка структуры/размеров UI без графического окна не равна визуальной проверке.
  Фактические тесты перечислены в `VERIFICATION.md`.
