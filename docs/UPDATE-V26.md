# v26 — обычные игровые модели, свет в облаках, сцена без ключа

## Персонажи заставки

Округлые/переосмысленные модели v22/v25 удалены из активного модуля. Восемь актёров используют **тот же `public/exports/player_super.glb`, что и игроки**: геометрия, лицо, волосы, одежда и эмблема не моделируются заново. Различаются только цвета внешности и позы.

- `SuperRig.sourceReady` позволяет заставке дождаться общей загрузки, без второго запроса GLB.
- `SkeletonUtils.clone` копирует модель, а геометрии, материалы и текстуры дополнительно отделяются для безопасной уборки.
- Старые native-узлы скрыты и служат контроллерами движения. Преобразования костей вычисляются через сохранённые bind-space offsets, без перезаписи исходных координат лица.
- Сохранены передача посылки, чтение, разговор, чашка, метла, покупки и телефон.
- Если пользователь сам отключил SuperRig, используется обычный native-персонаж игры, не v25. При ошибке загрузки включённого GLB — существующая обработка ошибки/пропуск, без подмены модели манекеном.
- Источник GLB и игровые ресурсы не изменяются и не освобождаются вместе с заставкой.

## Лестница

Убрана плоская полупрозрачная белая перегородка. В `fz-sky-descent.js` создан локальный облачный слой вокруг последних ступеней, белое свечение и источник света для ступеней, перил и площадки. Первые ступени остаются видимыми, последние теряются в облаках.

Используются существующие карты облаков/свечения, два собственных материала, 14 облачных спрайтов (9 в экономном/мобильном режиме), один источник света без теней. Нет дополнительного RAF, стробоскопа или изменения яркости всей сцены. Reduced motion отключает дрейф. Существующие коллизии, спуск от первого лица, пропуск и переход в город сохранены.

## Сцена администратора

- Окно `fzStageAccess`, ввод отдельного ключа и событие `sky:authorize` удалены. `FANTAZIA_STAGE_KEY` больше не используется.
- Сервер проверяет **обычную подтверждённую учётную запись** и её права. `sky:status` сообщает доступ; `sky:stage` проверяет его повторно перед входом. Проверка движения также повторяет проверку сессии.
- Локальному `isAdmin`, присланному нику/почте и клиентскому флагу администратора не доверяем.
- Обычные вход/регистрация связаны с существующим серверным API; токен передаётся при подключении к игре. Исправлен порядок JSON-парсера перед auth-маршрутами. Добавлено ограничение попыток входа/регистрации.
- Новые серверные аккаунты получают `role: user`; защищённые имена администратора нельзя занять через публичную регистрацию. Администратор — серверный аккаунт с `role: admin` либо существующий legacy-аккаунт из серверного списка администраторов без явной роли `user`.
- Если старый аккаунт существует **только в localStorage**, это не подтверждает серверные админ-права. Обычная игра по-прежнему доступна, но серверную роль нужно назначать владельцу сервера для настоящей учётной записи. Автоматической выдачи админки всем игрокам нет.
- Площадь, лестница и спуск открыты всем. Неадминистратор получает короткое уведомление вместо формы/запроса пароля.

## Проверки

- `cd tests && npm test`: **20 групп прошли**.
- Тест моделей сравнивает исходные вершины всех GLB-мешей, проверяет костные преобразования, удержание предметов, опорные стопы, детерминизм, reduced motion и неизменность исходной GLB-сцены после уборки.
- Новый интеграционный тест запускает настоящий `server.js` с изолированной временной базой: обычный вход администратора → сцена без ключа; поддельные ник/почта/роль и старый токен → отказ; смена токена отзывает старую сессию. База предпросмотра для этого теста не используется.
- Четыре браузерных набора прошли: `opening-native`, `opening-v22` (композитор с моделями v26), `sky`, `sky-visual`. Проверены реальные сцена/торговый центр, мобильный viewport, отсутствие формы ключа, спуск/пропуск, освещение, повторная уборка GPU-ресурсов и отсутствие JS/shader-ошибок.
- Просмотрены реальные кадры заставки и облачной лестницы. Проверки телефона — эмуляция viewport, не физическое устройство.

Предпросмотр работает на порту 3000. Публикации на GitHub и переупаковки прежних ZIP в этой правке нет.
