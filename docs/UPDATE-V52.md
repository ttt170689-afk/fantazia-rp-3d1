# V52 — Экспедиции

## Где открыть

В игре: **M → «Экспедиции · PvP, машины и заброшки»**. Выбери карту и режим.
Регистрация для этого не нужна. PvP требует подключения к серверу и второго игрока,
который выбрал ту же карту и режим. Пустая арена не подменяет соперника ботом.

## Содержание

- **Депо «Последняя смена»**: закрытая железнодорожная ветка, мастерские, реле,
  следы незавершённой эвакуации.
- **Карьер «Нулевая отметка»**: затопленные чаши с ограждениями, насосная,
  сухая кольцевая дорога и записи о пропавшем сигнале.
- **Обсерватория «Тихая частота»**: купол, антенны, архив сигналов и финал истории.
- Это три отдельные компактные игровые площадки, а не замена города или его зданий.
  Размер каждой — примерно 78 × 78 игровых метров. Корпуса служат укрытиями;
  новые многоэтажные интерьеры в этот выпуск не входят.
- **Экспедиция**: найти записи, включить три реле, вернуться к кругу эвакуации.
  Всего 12 записей. Вступление можно пропустить; после восстановления сигнала
  проигрывается финальная камера с анимацией победы. Режим уменьшенного движения
  отключает облёт камеры, декоративное покачивание и яркий след импульса.
- **Гончая, Слушатель и Сторож**: разные скорость, здоровье, дальность, урон и время
  подготовки удара. Перед атакой загорается кольцо; после неё есть окно восстановления.
  Импульс оглушает и наносит урон. Двигатель расширяет радиус обнаружения.
- **Ралли, Вездеход и Купе**: разный разгон, торможение, поворот и максимальная
  скорость. Посадка, двери, вращение колёс, задний ход, столкновения и безопасный
  выход после остановки. В сюжетной экспедиции можно пользоваться всеми тремя.
- **Заезд**: шесть последовательных точек по свободному периметру, таймер и личный
  рекорд. Выбранная машина выдаётся только на время заезда.
- **Дуэль**: два игрока, до пяти очков за поражение соперника или двух минут.
- **Контроль**: 2–6 игроков; очки получает единственный живой участник в центре.
  За поражение соперника — ещё три очка. Цель — 45 очков, лимит — две минуты.
  Общая таблица показывает счёт, поражённых соперников и собственные поражения.

## Управление

| Действие | Клавиши / интерфейс |
|---|---|
| Пешком | WASD |
| Поворот камеры / прицела | Перетаскивание по свободной области экрана, ← / → |
| Запись, реле, посадка / выход | E или «Действие» |
| Импульс | Space или экранная кнопка |
| Машина | W — газ; S — тормоз / задний ход; A/D — руль |
| Пауза одиночного режима | Esc или «Пауза» |
| Таблица PvP | Esc или «Таблица»; онлайн-раунд при этом не останавливается |
| Возврат | «В город»; без потери RP-вещей |

На телефоне доступны отдельные кнопки движения и перетаскивание камеры. Есть
портретная и альбомная раскладки; pointer cancellation освобождает нажатые кнопки.
Закрытие страницы, выход из игры и потеря сети освобождают сессию. При скрытии
страницы одиночная игра ставится на паузу; в PvP сервер останавливает устаревший ввод.

## Сохранения и границы

Городской персонаж не переносится в новую сцену: у экспедиции свои координаты,
здоровье, камера, противники и машины. Деньги, инвентарь, RP-здоровье, текущая позиция,
старый сюжет, комнаты, интерьеры и одобренные голоса не изменяются.

Записи, пройденные экспедиции и рекорды сохраняются **локально в этом браузере**,
раздельно по имени текущего профиля, ключ `fz_expedition52:<encoded username>`.
Это не облачная синхронизация и не защищённый глобальный рейтинг. Недоступный
localStorage не блокирует игру. PvP-счёт живёт только в текущем серверном раунде;
награды и списания из RP-экономики отсутствуют.

## Устройство и защита PvP

- `fz-expedition52-policy.js`: общие карты, коллизии с подшагами, лучи/видимость,
  управление, сюжетные состояния и валидация локального журнала.
- `fz-expedition52-world.js`: отдельная Three.js-сцена, собственные ресурсы,
  локальные процедурные текстуры, статический instancing, машины и существа.
  Персонажи используют независимые клоны существующего `player_super.glb`.
- `fz-expedition52.js`: жизненный цикл, меню, ввод, журнал и сетевой клиент.
  Рендер вызывается из существующего `animate`, без дополнительного RAF.
  sRGB применяется только на время отрисовки экспедиции и восстанавливается в `finally`.
- `server/expedition52.cjs`: 20 Гц симуляция, 10 Гц снимки состояния.
  Клиент передаёт только направление, поворот, последовательность и запрос выстрела.
  Координаты, цель, размер урона, здоровье и счёт от клиента не принимаются.
- Урон 25, ограничение стрельбы 0,45 с; проверяются дальность и стены.
  Возрождение через 3 с, защита нового появления 2 с, включая поздний вход в «Контроль».
- Ввод: конечные числа, ограниченные значения, возрастающий sequence, до 40 пакетов/с.
  Ввод старше 250 мс не продолжает движение. Неавторизованный в игровой сессии socket
  не может вступить в арену; имя берётся из зарегистрированного серверного игрока.
- Не более 32 комнат. Повторный вход ограничен одной секундой; одиночное ожидание
  закрывается через 3 минуты, законченная комната — через минуту. Disconnect очищает
  членство и лимитеры. Приватные MAIN/owner API не меняются.

## Проверки

```sh
npm ci --no-audit --no-fund
npm ci --prefix tests --no-audit --no-fund
npm run test:expeditions
npm run test:expeditions:browser
```

- **30 unit / socket-тестов**: достижимость целей на трёх картах, свободный маршрут
  с учётом габаритов машины, отсутствие прохода сквозь стены, разгон/тормоз/реверс,
  стороны управления, взаимодействия по близости и видимости, атаки всех существ,
  фильтрация журнала, авторитетное движение/урон, защита появления, лимиты и TTL.
- **Реальный гостевой сервер и два socket-клиента**: opt-in, одна комната, движение,
  отклонение незарегистрированного участника, выход соперника и конец раунда.
- **Нативный браузер/WebGL**: вход через настоящее M-меню, три сцены, настоящие
  GLB-клипы idle/run/point, посадка и езда, пауза, запуск заезда, оба онлайн-режима
  с отдельным гостевым socket-клиентом, создание удалённого персонажа, завершение,
  портрет 390 × 844 и альбом 844 × 390, освобождение pointer input, возврат в город.
- **Изолированная WebGL-сессия**: реальные контроллер и сцены, чтение первой записки
  с движением через клавиши, пауза читателя, вступительная и финальная камеры,
  reduced motion, шесть типов анимации персонажа, ноги существ, предупреждение об
  ударе, колёса/двери, проигрыш и повтор, смена профиля, независимость скелетов.
  Граничные состояния завершения задания и заезда подготавливаются через ссылки
  тестовой fixture; это не заявление о ручном полном прохождении каждого маршрута.
- После шести циклов создания/удаления сцен: **40 геометрий / 80 текстур до и после**
  в контрольной fixture, WebGL error = 0, ошибок страницы нет.
- Статическая группировка снизила число draw calls в контрольных нативных кадрах:
  депо **338 → 119**, карьер **217 → 116**, обсерватория **239 → 122**.
  Это измерение конкретных тестовых кадров, не обещание FPS на любом телефоне.
- Проверены регрессии quality/sound/play, room48, interior50, funeral51, public access.
  Отдельный job `expeditions` добавлен в существующий GitHub Actions workflow.

Скриншоты тестов создаются в `.cache/expedition52/`, в Git не включаются.
Браузерная проверка использует программный WebGL; физическое Android/iPhone-устройство
не тестировалось. Графика стилизованная и процедурная; новых записанных голосов,
APK/EXE или производственной публикации этот выпуск не создаёт.
