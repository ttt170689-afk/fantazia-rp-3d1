# Обновление 47 — путевой дневник

## Новое для игрока

- Три новые физические записки: **«Квитанция без срока»** в задней части архива,
  **«Место у двери»** в лечебном корпусе, **«Ответ на чистой частоте»** у берега.
  Теперь в мире 15 записей. Старые 12 остаются на месте.
- В **M → Инвентарь и дневник** появились поиск по названию/тексту/месту и фильтр
  по месту находки. Поиск нечувствителен к регистру и различию «е/ё».
- Найденные записи можно перелистывать кнопками «Предыдущая» / «Следующая».
  Возврат к списку сохраняет текущий поиск и фильтр.
- Режим крупного текста запоминается в этом браузере. Если браузер не разрешает
  хранить настройки, переключатель всё равно действует в текущем сеансе.
- На телефоне — одноколоночный поиск и прокручиваемый текст; кнопка закрытия
  остаётся в верхней части карточки. Escape закрывает дневник, Tab остаётся внутри.
- Набор текста в поиске больше не перехватывается игровыми клавишами.

Это добровольное исследование: нет новых обязательных заданий, таймеров,
автоматических окон или индикаторов на HUD. Скрытые записи не показываются
через поиск и не открываются перелистыванием.

## Совместимость

Схема сохранения не менялась: новые идентификаторы входят в существующий
ограниченный список `adventure45.notes`. Старое сохранение с 12 записями сохраняет
их все; три новые нужно найти самостоятельно. Припасы и состояние щита связи
не сбрасываются. Поиск, фильтры и размер текста не изменяют игровой прогресс.
При смене загруженного профиля открытый дневник закрывается, поиск сбрасывается.

Гостевые сохранения остаются браузерными, серверные — для существующего MAIN-
аккаунта. Права владельца, сцена, экономика, выбранные голоса и сюжетные сцены
в этом обновлении не менялись. Новые тексты не получили новой голосовой записи.

## Проверки

- `npm run test:journal`: построение 15 физических записок через Three.js,
  старые сохранения и очистка неизвестных ID, запрет удалённого подбора,
  поиск/фильтры/перелистывание только найденного, крупный текст, фокус,
  смена профиля и освобождение ресурсов.
- `npm run test:journal:browser`: реальный интерфейс в Chromium на 1280×800 и
  390×844, поворот на 844×390, ввод с клавиатуры, фильтрация, крупный текст,
  Escape и Tab. Для этого UI-теста найденные записи заранее заданы в отдельном
  тестовом профиле; это не проверка прохождения маршрута по миру.
- `npm run test:quality:browser`: настоящий запуск WebGL и первой сцены,
  переподключение; дополнительно проверяется, что каждой записи каталога
  соответствует физический объект в сгенерированном мире.
- Повторно выполнены проверки качества, публичного доступа и браузерного меню.
  Новые проверки включены в CI.

Исторические тесты, ожидающие ровно 12 записок (например, старый `update45`),
требуют обновления ожиданий и подключения нового модуля читателя. Они не
переписывались поверх ранее оставленной незавершённой работы.

Перед выпуском остаётся вручную проверить подход к новым запискам обычным
маршрутом и экранную клавиатуру на настоящем телефоне. Ветка/PR обновляются;
объединение main и публикация на Render не выполняются автоматически.
