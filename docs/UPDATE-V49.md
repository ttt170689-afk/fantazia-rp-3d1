# Обновление 49 — детали комнаты и удобное взаимодействие

Продолжение 2D-пролога «Последний сеанс» из обновления 48.

## Что изменилось

- Настольная лампа стала интерактивной: E, кнопка действия или касание рядом
  включают/выключают её. Тёплый ореол и световой конус плавно затухают.
- Добавлены тканый ковёр, контактная тень дивана, клавиатура, мышь, провод,
  отметка цели движения и постепенно печатающийся текст при запуске компьютера.
- Касание самого предмета издалека задаёт маршрут, рядом — выполняет действие.
  Подход сам по себе не запускает компьютер. У предметов отдельные области
  попадания; действие E выбирает ближайший, а не первый предмет в списке.
- Выпадающий список позволяет выбрать компьютер, лампу, записку или дверь,
  затем подойти кнопкой. Стрелки в списке не двигают персонажа.
- Подсказки зависят от предмета, маршрута и состояния лампы. Реплики записки,
  двери и лампы временно сохраняются перед возвращением обычной подсказки.
- «Меньше эффектов» запоминается в этом браузере (`fz_room49_reduced`). До первого
  явного выбора действует прежняя настройка уменьшения движения. Запрет записи
  в localStorage не мешает игре. Это настройка комнаты, не аккаунтное сохранение.
- Исправлено колебание автоподхода около промежуточной точки при редких кадрах:
  шаг ограничен оставшимся расстоянием, завершённый маршрут очищается.
- Пауза очищает движение и цель; возврат фокуса не попадает на отключённую кнопку.
  В альбомном режиме телефона подсказка и управление находятся в отдельных
  строках сетки, чтобы не перекрываться.

## Совместимость

Сохранены пропуск/меню, отсутствие комнаты при сохранённой позиции или уже
просмотренном вступлении, защита от устаревшего запуска, освобождение RAF и
обработчиков, существующий звук и переход к настоящему 3D. Новых флагов истории,
аккаунтов, голосовых записей и 3D-моделей нет. Лампа использует существующий SFX.

## Проверено локально

- `npm run test:room`: движение на 10/15/30/60/144 Гц, завершение маршрута,
  ближайший предмет/попадания, лампа/затухание, настройки с доступным и запрещённым
  хранилищем, прежние проверки отмены, паузы, сохранений и жизненного цикла.
- `npm run test:room:browser`: настоящий сервер, клавиатура и эмуляция touch,
  касания лампы/компьютера, список направлений, повторный вход с настройкой,
  портрет/альбом и отсутствие перекрытия подсказки управлением, пауза/отмена.
- `npm run test:quality` и `npm run test:public` — успешно.
- `npm run test:quality:browser`: комната с обычными эффектами → настоящий WebGL,
  анимированный GLB, первая сцена дождя, переподключение; `PAGE_ERRORS []`.
- `npm run test:public:browser`: гостевой вход и меню, звук, отказ аудио,
  таймаут сессии, offline/reconnect на desktop и эмулируемом mobile — успешно.
- Просмотрены снимки 1280×800, 390×844 и 844×390. Первое снятие мобильного снимка
  превысило таймаут инструмента; повтор с увеличенным таймаутом завершился.

Эти результаты не означают полный проход сюжета или проверку производительности
на физическом телефоне. Прежние ограничения общего аудита не отменены.
Изменения поставляются в рабочей ветке / PR №5, без публикации в main, Render,
APK или EXE.
