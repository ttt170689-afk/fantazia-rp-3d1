# Открытая игра без регистрации

По подтверждённому решению владельца сайт больше не требует бета-допуск,
регистрацию, пароль или код из лаунчера для обычной игры.

## Поведение

- `/` и игровые ресурсы доступны всем; меню сразу получает гостевой профиль.
- Гость может подключаться к Socket.IO и играть. Имя и отсутствие прав
  назначает сервер, а не присланный клиентом ник/роль.
- Гостевые профили не добавляются в MAIN или постоянную базу аккаунтов.
- Точка сохранения может оставаться в браузере. Переноса гостевого прогресса
  между устройствами нет. Это не серверный аккаунт.
- `/closed/login` ведёт на главную. Старые маршруты кодов лаунчера отключены
  в публичном режиме. Бета-таблицы Supabase не удалены: они могут требоваться
  отдельному лаунчеру, но сайт больше не использует их для допуска.
- Необязательный вход в СУЩЕСТВУЮЩИЙ MAIN-аккаунт: `/account/login`.
  Подтверждение личности и серверные сохранения сохранены; одобрение Fantazia
  не проверяется. Регистрация нового аккаунта на сайте не включается.
- Админ-API, управление магазином, игровые админ-команды и сцена по-прежнему
  доступны только подтверждённому владельцу. Смена ника на имя владельца,
  поддельный токен, isAdmin/role в Socket.IO и гостевой cookie прав не дают.
- Приватные данные/серверные сохранения недоступны гостям; чужой токен в теле
  запроса не позволяет читать/перезаписывать аккаунт.

## Хранилище и конфигурация

Существующий FANTAZIA_RUNTIME_SECRET и постоянное хранилище не меняются.
Сервер не создаёт пустую базу вместо недоступной. При ошибке записи хранилища
уже запущенный сервер продолжает отдавать публичные ресурсы и гостевую игру,
но приватные операции блокируются. Для первоначального запуска по-прежнему
нужна корректная конфигурация хранилища; это не снятие защиты сохранений.

Существующие MAIN cookies читаются совместимо. `__Host-fantazia_guest` —
защищённый HttpOnly/Secure/SameSite cookie случайного гостевого идентификатора,
не отдельная регистрация. Он не содержит прав администратора.

## Проверки

- `npm run test:public` — настоящий Node/Socket.IO сервер: публичные ресурсы,
  подключение без аккаунта, запрет подделки владельца, гостевого сохранения
  в чужой аккаунт, админ-команд и входа на сцену; владельцу сцена доступна.
- `npm run test:public:browser` — Chromium, десктопный и мобильный размер:
  гостевое меню и кнопка «Играть» без регистрации, возврат в гостевой режим.
  Это не полный прогон игрового мира или проверка FPS на физическом телефоне.
- Старые изолированные тесты closed-модуля сохранены как регрессионные;
  сам `server.js` теперь подключает `installPublicAccess`, а не `installClosedBeta`.

## Публикация

Изменения находятся в текущей рабочей ветке/PR. До их объединения и развёртывания
на Render боевой сайт может показывать прежний вход. Изменения в этом проекте
не обновляют уже установленный отдельный TemkaLauncher: его собственная
блокировка установки/запуска по заявке требует отдельного обновления лаунчера.
