# 🎬 Музыка концовки тизера — Fantazia RP 3D1

Тёмная кинематографичная тема под финальные титры тизера:
**FANTAZIA RP мигает → перечёркивается → GRAND MALL SECRET → SOON**.

## Файлы
| Файл | Что это |
|---|---|
| `teaser-outro.mp3` / `.wav` | Музыка только концовки (12.6 сек) |
| `trailer-full-ost.mp3` / `.wav` | 🎬 **СУПЕР-МЕГА-ХОРРОР саундтрек ВСЕГО трейлера** (38.6 сек) |
| `make_teaser_outro.py` | Генератор концовки |

| `index.html` | Страничка-плеер |

## Как послушать в самом тизере
Добавь параметр: `teaser.html?music=1` — полный саундтрек заиграет
синхронно со всеми событиями (опция; по умолчанию выключен).


## Тайминг (синхронизирован с титрами в public/teaser.html)
| Время | Событие на экране | Музыка |
|---|---|---|
| 0.0 | FANTAZIA RP мигает | саб-дрон A1 + «удары сердца» |
| 3.4 | FANTAZIA RP перечёркивается | удар + скрежет + диссонанс |

## Как встроено в тизер
В `public/teaser.html` добавлена функция `startOutroMusic()`, вызываемая в куе
`t=24.80` (момент `T.phase='end'`). Использует штатный аудио-движок тизера
(`tone`, `noiseBurst`) — без внешних файлов, работает даже офлайн.
Гард `window._fzOutro` сбрасывается в `resetShow()`.
