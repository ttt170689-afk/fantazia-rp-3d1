# 🎬 Музыка концовки тизера — Fantazia RP 3D1

Тёмная кинематографичная тема под финальные титры тизера:
**FANTAZIA RP мигает → перечёркивается → GRAND MALL SECRET → SOON**.

## Файлы
| Файл | Что это |
|---|---|

## 🎬✨ Кинематографичный саундтрек v2 (39.4 c) — что внутри

- **Стерео 48 кГц**, свёрточная реверберация «каменный зал» (IR 2.4 с, нормирован по энергии), мягкий клиппер, секционная автоматика громкости
- **0–15.5 — подход**: тёплые струнные пэды (3 расстроенных голоса × 12 гармоник, «дыхание»), гармония Am(add9) → Fmaj7/A → Cmaj9/G → Em(add9) с нарастанием, мелодия-калимба, воздух
- **💓 Сердцебиение**: суб-свип 96→36 Гц + шумовой щелчок (луб-дуб), разгоняется **52→115 BPM** и становится громче по мере приближения к 15.5 с
- **15.5 рубильник / 18.05 глюк / 20.85 грохот / 24.8 титры / 32.0 SOON** — все события на своих местах, удары с низким кластером и хвостом реверберации

## Как включить в тизере
- **По умолчанию** теперь: при показе (0–15.5 с) играет красивая музыка подхода (пэды+калимба) и реалистичное сердцебиение `heartDyn`/`fzHB` — прямо в коде, без файлов.
- `teaser.html?music=1` — играет **кино-файл** `teaser-cinematic.mp3` синхронно с роликом (полная версия со всеми ударами).
- `teaser.html?music=2` — старая синтезная версия.

Добавь параметр: `teaser.html?music=1` — полный саундтрек заиграет
синхронно со всеми событиями (опция; по умолчанию выключен).

## Как встроено в тизер
В `public/teaser.html` добавлена функция `startOutroMusic()`, вызываемая в куе
`t=24.80` (момент `T.phase='end'`). Использует штатный аудио-движок тизера
(`tone`, `noiseBurst`) — без внешних файлов, работает даже офлайн.
Гард `window._fzOutro` сбрасывается в `resetShow()`.
