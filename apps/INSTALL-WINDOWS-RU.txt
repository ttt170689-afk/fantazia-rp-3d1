FANTAZIA RP — ОНЛАЙН-КЛИЕНТ ДЛЯ WINDOWS
Версия оболочки 1.0.0 · Windows 10/11 x64

1. Распакуй скачанный архив артефакта сборки.
2. Запусти Fantazia-RP-Setup-1.0.0-x64.exe.
3. Выбери папку установки. Установщик создаёт ярлык Fantazia RP.
4. Открой приложение и введи HTTPS-адрес своего игрового сервера.
5. Нажми «Подключиться», затем войди в аккаунт уже внутри игры.

АДРЕС СЕРВЕРА НЕ ЗАШИТ В ЭТУ СБОРКУ.
Нужен работающий сервер Fantazia RP с HTTPS. Адрес репозитория,
страница Actions и архив ZIP — НЕ адреса игрового сервера.
Установщик не размещает сервер и не является офлайн-версией.
Если своего адреса ещё нет, сначала нужен хостинг игрового сервера.

На компьютере игрока Node.js/npm и браузер устанавливать не нужно.
Это оболочка существующей веб-игры, а не перенос на другой 3D-движок.
Графика, персонажи и содержание определяются версией игры на сервере.
Установка клиента НЕ обновляет сайт до v45 автоматически.

F10 — вернуться к выбору сервера.
F11 — полный экран.
Ctrl+R — перезагрузить игру.
Закрытие окна игры возвращает к подключению. Закрытие окна подключения
или «Игра → Выход» завершает приложение.

СОХРАНЕНИЯ
Войди в тот же аккаунт на том же сервере: серверные сохранения v41+
загрузятся в игре. Пароль в настройках оболочки не хранится.
Адрес сервера и браузерный профиль клиента находятся в пользовательской
папке приложения (AppData\Roaming\Fantazia RP 3D), не рядом с EXE.
Настройки/несинхронизированные данные Chrome автоматически не импортируются.
Не удаляй accounts.json на сервере при обновлении самой игры.

БЕЗОПАСНОСТЬ И ПОДПИСЬ
Сборка не имеет коммерческой цифровой подписи издателя. Windows может
показать предупреждение о неизвестном издателе. Сверяй источник и SHA-256
из SHA256SUMS.txt; антивирус отключать не требуется.
Микрофон запрашивается отдельно. Камера и доступ страницы игры к Node.js
не разрешены. Проверка HTTPS-сертификатов не отключена.

ПРОВЕРКИ
Windows-сборка включает тест подключения к тестовому HTTPS-ответчику,
изоляции удалённой страницы, установки, запуска установленного приложения
и запуска удаления. Настоящий игровой сервер в эти проверки не входит:
его адрес пока не задан. FPS на пользовательском ПК не гарантируется.

Артефакт GitHub Actions хранится 14 дней. Сохрани установщик у себя.
Сборка НЕ опубликована в GitHub Releases, магазине или на игровом сайте.
