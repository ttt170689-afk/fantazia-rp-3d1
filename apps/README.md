# Fantazia — исходники оболочек Android / Windows

**Это не готовые APK/EXE. Установщики не собраны и не проверены.**
Здесь подготовлены конфигурации, безопасный запуск удалённой игры и lockfile.
В рабочей среде нет Android SDK/JDK и средств сборки Windows; загрузка
нативных инструментов ограничена. Проверены Node-синтаксис и политика URL.

Обе оболочки открывают **постоянный HTTPS-адрес вашего игрового сервера**.
Они не запускают Node/Socket.IO сервер на телефоне и не превращают сетевую
игру в офлайн-игру. Адрес временного предпросмотра не подходит для релиза.

## Общая подготовка

Нужен Node.js 22+ с npm. На машине сборки:

```powershell
cd apps
npm ci
$env:FANTAZIA_GAME_URL = "https://ВАШ-ПОСТОЯННЫЙ-ДОМЕН/"
npm run configure
npm run check
```

Вместо примера укажите настоящий работающий домен. HTTP, localhost,
встроенные логины/пароли и токены в адресе отвергаются. Сгенерированные
`game-config.json` и `capacitor.config.json` не коммитятся. В конфигурации
**нет ключа сцены** и никаких административных прав.

## Android / APK

1. Установить актуальную Android Studio с SDK и JDK, подходящими для
   Capacitor 8. Следовать проверкам Gradle/Android Studio для выбранной версии.
2. Выполнить:

```powershell
npm run android:add
npm run android:sync
npm run android:open
```

`android:add` выполняется один раз и генерирует каталог `apps/android`.
При следующих изменениях достаточно `android:sync`.
3. В Android Studio дождаться Gradle Sync. Для тестирования — Run на
   подключённом устройстве. Для установочного файла — Build APK(s).
4. Для распространения — Generate Signed Bundle / APK, собственный keystore
   и версия приложения. Keystore/пароли не хранить в репозитории или чате.
   Неподписанный debug APK не считать готовым релизом.
5. Проверить WebGL, вход, обе ориентации, системные отступы/клавиатуру,
   джойстик+камеру двумя пальцами, фото/скачивание, возврат после фона и сеть.
   Голосовой чат требует отдельной проверки разрешений WebView/Android;
   при необходимости добавить RECORD_AUDIO и запрос разрешения в native-проект.

Шаблон не блокирует ориентацию. Это WebView-оболочка текущей браузерной игры,
а не отдельный нативный 3D-движок.

## Windows / EXE

На Windows 10/11 x64:

```powershell
npm run desktop
npm run windows:build
```

Вторая команда собирает NSIS-установщик в `apps/release` с помощью
Electron Builder. При отсутствии сертификата Windows может показывать
предупреждение SmartScreen. Для публичного выпуска нужна подпись владельца.

Удалённая страница изолирована: `nodeIntegration: false`, `contextIsolation`,
`sandbox`, запрет встраиваемых webview и переходов главного окна на чужой origin.
Микрофон — только после явного подтверждения в системном диалоге оболочки;
видео и прочие ненужные разрешения не выдаются. Нет отключения проверки TLS.
При ошибке загрузки предлагаются повторная попытка и закрытие.

## Важные ограничения

- Изменения игры на сервере доступны оболочкам после перезагрузки. Для
  обновления самого Electron/Capacitor нужно пересобрать приложение.
  Автообновление установщика и публикация в магазине не настроены.
- Старые аккаунты/часть прогресса игры находятся в localStorage браузера.
  WebView и Electron используют другие хранилища: прогресс **не переносится
  автоматически** из Chrome/Safari. Нужна отдельная серверная миграция аккаунтов.
- ASAR, APK и отключённое контекстное меню не скрывают исходный JavaScript
  и не защищают сервер. Секреты/права должны оставаться на сервере.
- Перед публичным выпуском устранить блокеры авторизации, описанные в
  `docs/PHONE-READINESS.md`, и протестировать реальные устройства.
