FANTAZIA RP — ФАЙЛЫ КЛИЕНТА ДЛЯ WINDOWS / ЛАУНЧЕРА
Версия оболочки 1.0.2 · Windows 10/11 x64 · PORTABLE ZIP

Без установщика. Распакуй ВЕСЬ архив в отдельную папку.
Запускаемый файл в корне: Fantazia RP 3D.exe
Рабочая папка процесса: папка, где находится этот EXE.
Node.js, npm и отдельный браузер на ПК игрока не нужны.

ДЛЯ TEMKALAUNCHER
Загружай именно Fantazia-RP-Portable-1.0.2-win-x64.zip, а не внешний архив
артефакта GitHub Actions. Лаунчер должен распаковать ZIP целиком и запускать
Fantazia RP 3D.exe. Не вынимай один EXE: рядом обязательны DLL, resources,
locales, лицензии Electron/Chromium и остальные файлы архива.
Формат собственного каталога/автообновления TemkaLauncher здесь не задаётся.
Перед заменой файлов обновления закрой работающую игру.
SHA-256 опубликован рядом с архивом. Установщик NSIS в этот пакет не входит.

ЭТО ОНЛАЙН-КЛИЕНТ, НЕ ОФЛАЙН-ИГРА
При запуске клиент автоматически подключается к основному серверу:
https://fantazia-rp-3d1.onrender.com/
Вводить адрес не нужно. Старый сохранённый preview URL не подменяет основной
сервер при новом запуске. Если Render просыпается, клиент ждёт до 2 минут.
При ошибке можно повторить подключение или исправить адрес.
Адрес репозитория, файла ZIP или страницы Actions не подходит.
Войди в свой аккаунт на том же сервере — серверный прогресс v41+ загрузится.
Версия содержимого игры определяется сервером, не номером оболочки.
Этот ZIP сам по себе не публикует новую версию игры на Render.

F10 — подключение / смена сервера. F11 — полный экран. Ctrl+R — перезагрузка.
Выход: закрой окно подключения либо «Игра → Выход».
Профиль хранится отдельно в AppData\Roaming\Fantazia RP 3D.
Это portable-дистрибутив БЕЗ установки, но не режим «все данные на флешке».
При обновлении папки с игрой профиль не стирается.

Сборка не имеет цифровой подписи издателя: Windows может предупреждать
о неизвестном приложении. Проверяй источник и SHA-256; защиту отключать не нужно.
Проверка Windows-сборки: распаковка, наличие ресурсов, открытие настоящего
окна приложения и нормальное завершение. Производительность на личном ПК
и подключение к основному серверу требуют отдельной проверки.

НА ANDROID ЭТОТ ZIP НЕ РАБОТАЕТ
Android-приложение распространяется как APK и устанавливается системой.
Запуск игровых файлов без установки возможен лишь внутри совместимого
Android-лаунчера с собственным WebView/движком. Это отдельный формат.
