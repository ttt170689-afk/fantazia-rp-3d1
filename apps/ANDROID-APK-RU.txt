FANTAZIA RP — ANDROID-КЛИЕНТ ДЛЯ ЗАГРУЗКИ ИЗ ЛАУНЧЕРА
Android 8.0+ (API 26), актуальный Android System WebView
Версия клиента: 1.0.1. Игра загружается с выбранного HTTPS-сервера.

ДВА РАЗНЫХ ПАКЕТА
1. Fantazia-RP-TEST-1.0.1-android.apk
   Проверочный APK: приложение «Fantazia TEST», ID org.fantazia.rp3d.preview.
   Подписан временным debug-ключом CI. НЕ предназначен для публичного выпуска
   с гарантированными обновлениями. Между сборками подпись может отличаться.
   Не заменяет основное приложение. Не называй его production-релизом.
2. Fantazia-RP-1.0.1-android.apk
   Публичный пакет с ID org.fantazia.rp3d. Он появляется ТОЛЬКО после настройки
   постоянного ключа в GitHub Secrets. Если подпись не настроена, такого файла
   в результатах сборки нет. Тестовый APK не становится релизным от переименования.

КАК ЗАПУСКАЕТ ЛАУНЧЕР
Скачать APK → передать его стандартному установщику Android → после согласия
пользователя запускать установленный пакет. Если требуется разрешение установки
из источника, выдавай его только своему доверенному лаунчеру. Отключать защиту
телефона не нужно. На обычном Android нельзя тихо распаковать APK как EXE и
запустить без установки; автоматической скрытой установки здесь нет.

Сам лаунчер отвечает за DownloadManager/свой механизм загрузки, FileProvider
и системный install Intent. Подключение к TemkaLauncher этим пакетом не меняется.
Архив артефакта GitHub сначала распакуй: в каталог лаунчера загружай сам APK.
Проверяй SHA-256 из SHA256SUMS.txt.

ПРИ ПЕРВОМ ЗАПУСКЕ
Укажи основной HTTPS-адрес своего игрового сервера Render, нажми «Подключиться»
и войди в тот же аккаунт. Временный адрес PR не зашит в приложение.
Серверная точка сохранения v41+ загрузится после входа на тот же сервер.
Node.js игроку не нужен. Без работающего сервера клиент не является офлайн-игрой.

В окне игры: «Сервер» — вернуться к подключению, «Полный экран» — скрыть панель,
системная кнопка/жест Назад — вернуть панель. «Браузер» открывает сервер в браузере.
Микрофон запрашивается отдельно для голосового чата; камера не разрешается.
Фото/скачивание через blob в этой минимальной WebView-оболочке не реализовано:
для сохранения фото используй кнопку «Браузер» и функцию фото на сайте.

ОБНОВЛЕНИЯ
Для обновления без удаления приложения нужны тот же applicationId, тот же
ключ подписи и больший versionCode. Ключ и пароли не добавляй в репозиторий,
артефакты, чат или пакет игры. Настройки — в данных приложения, игровой прогресс
на сервере. Если у тебя уже был подписанный публичный APK, используй его исходный
ключ и проверь совместимость applicationId; новый ключ не заменяет старый.

ПРОВЕРКИ И ОГРАНИЧЕНИЯ
Workflow компилирует APK, выполняет Java-тесты URL/разрешений, Android lint и
эмуляторную проверку экрана подключения/отказа небезопасным адресам/пересоздания
Activity. Это НЕ полный игровой прогон на физическом телефоне. Реальный сервер,
WebGL, звук, голосовой чат и производительность требуют проверки на устройстве.
Новый игровой контент и публикация сервера не входят в эту сборку оболочки.
