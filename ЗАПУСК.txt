FANTAZIA RP 3D — как запустить игру
=====================================

1. Установи Node.js (https://nodejs.org) — один раз.
2. Распакуй архив.
3. Открой папку игры в терминале и выполни один раз:
     npm install
4. Запусти сервер:
     node server.js
   (или: npm start)
5. Открой в браузере:
     http://localhost:3000

Скриншоты для страницы:
- кнопка ФОТО 📷 в боковой панели игры сохраняет чистый
  скриншот без интерфейса в папку «Загрузки».
- Формат PNG, имя fantazia-<время>.png

Приятной игры!
